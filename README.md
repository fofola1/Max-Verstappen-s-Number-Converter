# 🏎️ Max Verstappen's Number Converter

Are standard base-10 numbers lacking top speed? Does standard math feel completely undriveable, jumping around like a kangaroo?

Welcome to the **Max Verstappen's Number Converter**, a revolutionary CLI tool that translates your boring, everyday integers into the only delta that matters: **Base 69**.

Whether you're surviving turn one, arguing with GP on the radio, or staying up until 4 AM doing iRacing endurance stints before a Grand Prix, this script calculates the exact gap to P2 so you don't have to. Simply lovely.

---

## 🛠️ Installation

You don't need a multi-million dollar wind tunnel to get this running. Just standard Python 3, which means hard drive with a few gigabytes of space required if you don't have it already, but that's about it.

**1. Clone the repo:**
```bash
git clone [https://github.com/fofola1/Max-Verstappen-s-Number-Converter](https://github.com/fofola1/Max-Verstappen-s-Number-Converter.git)
cd Max-Verstappen-s-Number-Converter
```

**2. Run the script:**
This will get you to the help page where you can see how to use it.
```bash
python verstappen-converter.py
```

---

## Command Line Arguments

| Argument | Flag | Description |
| --- | --- | --- |
| **`number`** | (Positional) | The integer you want to convert into Max's delta. |
| **`--result-only`** | `-r` | Suppresses the team radio. Use this when you want GP to stop talking to you in the braking zones. |
